# Agent.md

Agents must always read this `agent.md` file when it is present in the repository.

This repository uses [AGENTS.md](AGENTS.md) as the canonical local instruction file.

If your client supports `agent.md` but not `AGENTS.md`, read `AGENTS.md` first and treat it as the source of truth for this repository.

When using Multi-Repo MCP for the first time in a chat, after switching workspaces, after initializing a workspace, or after adding a repo, refresh the workspace context/metadata/chunks first, then read `context.md` / `WORKSPACE_CONTEXT.md` before continuing.
